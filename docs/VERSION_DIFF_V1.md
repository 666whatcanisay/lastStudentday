## 五、单口令（本轮改动）

- **只有一个口令**，登录后即完整管理员：无账号体系、无第二个管理员口令。
- 复用原有加盐哈希（pbkdf2_sha256 / 600000 次）+ 内存会话 + 后端权限中间件，**没有新造鉴权**。
  实现方式：未配置访客口令时自动进入单口令模式（`DemoSettings.single_password`），登录分支把该口令判为 `admin`。
- **明文不落盘、不进仓库**：口令以哈希存在被 `.gitignore` 排除的 `.env` 里。
- **权限是后端强制的**，不是前端藏按钮。未登录时以下全部返回 401（已实测）：
  列表 / 统计 / 分析 / 原件预览 / 导出 / RAG 配置 / 备份。
- 口令管理：`scripts/setup_demo_auth.py --status | --set-password "新口令" | --disable`。

## 七、遗留事项

- **公网访问（Tailscale Funnel）本机代码路径已全部验证通过，但尚未开启**：
  本机 Tailscale 守护进程卡在 `NoState`（服务在跑但连不上协调服务器），重启服务需要管理员权限，我这边没有。
  需要你先**以管理员身份重启 Tailscale 服务**（或打开 Tailscale 客户端登录），之后执行：

  ```powershell
  scripts\tailscale_funnel.bat status   # 自检：未登录必须 401
  scripts\tailscale_funnel.bat up       # 开公网映射
  ```

  详见 `docs/TAILSCALE_DEMO.md`。应用仍只监听 `127.0.0.1`，Funnel 只反代一个 HTTPS 端口。

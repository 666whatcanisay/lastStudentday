## 失败处理

- 完整备份或预检失败：**不改 `.env`、不移动旧目录**，排障后重试。
- 新目录恢复失败：保留恢复日志与快照；旧数据根仍为权威来源，不启动指向半成品新库的服务。
- 切换后、**尚无新写入**时只读冒烟失败：停新版，将 `.env` 指回旧数据根并按原方式启动；保留新目录现场供排查，不盲目删除。
- 一旦新库已接受业务写入，旧库就不是无损回退点；必须先保全新库，再决定修复或从新库备份恢复，不能直接切回旧库抹掉新写入。

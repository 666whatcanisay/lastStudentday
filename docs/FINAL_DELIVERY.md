# v1.1.0 本机交付结论

交付范围：现有四个业务板块的精修、旧数据保守核对、独立运行环境、源码封版与接手/讲解材料。不新增模型供应商、部署方式或大功能；不自动推送远程仓库，不自动重新开启 Funnel。

## 完成情况

- 文档页拆为上传、列表与校对组件；同页板块用文档变化通知更新。移动端卡片、筛选折叠、问答过程折叠已实现。
- 统计/导出路由拆分，原 URL、权限与数据库 schema 保留；未知字段、币种和日期口径不偷换。
- 独立 `.venv` 由安装脚本建立并通过关键依赖导入自检；启动、停止、离线恢复均支持同一本机 `.env` 数据根目录。
- 26 份有效旧文档获用户一次确认后，通过 PATCH API 保守保存并标记当前版本已校对；原件未改，旧版本保留。现为 5 发票、5 合同、16 其他，均在 r2。原库另有 1 份无有效版本的识别失败记录，未伪装成成功或删除。
- 11 份业务日期仍未知；10 份发票/合同币种仍未知。金额图表不产生猜测币种合计；合成样本的未来日期没有改成“像真的”日期。
- 切换前全量备份已另存其他磁盘，并用恢复预检验证清单、成员哈希与数据库。私有路径与哈希在本机 `reports/LOCAL_HANDOVER.md` 和 `legacy_applied.json`，不入公开源码包。

- 新独立环境：后端单测 39/39 通过，前端生产构建通过。
- P1–P4：16/16 通过，无跳过；包含迁移、备份恢复、版本冲突、OCR、索引、统计、PDF/ZIP、Excel 和完整流程。
- 精修阶段浏览器：1440、768、390px 主要页面无横向溢出，手机上传识别与下载已实测。

结果文件在被忽略的 `reports/acceptance/` 与 `reports/handover_smoke/`；它们包含本机路径/数据，不公开。无需把测试报告硬塞入源码仓库来证明测试存在，接手人可自行运行脚本复现。

## 签收边界

本机单机交付可以签收；演讲公网开放仍须负责人用手机移动数据做最后彩排。本轮没有重新开放 Funnel，也没有声称完成跨网络真人设备验收。

真实云端生成没有主动付费调用，本地检索已验证、云端失败降级由隔离测试覆盖。访问口令**已切换为单口令模式**（未配置访客口令时自动降级为单口令，登录即完整管理员），沿用原有 pbkdf2_sha256 加盐哈希，明文不落盘、不进仓库。需要更换口令时用 `scripts/setup_demo_auth.py --set-password "新口令"`（`--status` 可查看当前配置），并在本机另行记录。

测试通过不等于无限并发、任何文件必定识别正确或安全审计已经穷尽。当前仍是 Windows、单进程、SQLite、本机 CPU 的项目定位。

## 安全回退

若新版异常，先关闭任何 Funnel 入口，停止新版，保留日志。必要时用本机恢复脚本加载切换前备份，再用原代码启动；不能把备份中的旧数据库直接覆盖正在运行的数据库。若只是界面问题，优先保留修正后的正式数据，不随意撤销已确认的校对。

同一数据目录只能由一个服务占用；双击停止脚本只停止记录且身份核验通过的本应用。恢复故障保留快照和日志，不删除恢复日志强行启动。
